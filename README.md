# UGL App – Universal Grounded Language

UGL es una aplicación móvil que permite comunicación multilingüe en tiempo real
mediante un lenguaje universal basado en significado, no en idiomas.

## Qué hace este MVP
- Escucha voz
- Detecta idioma automáticamente
- Convierte a UGL (lenguaje universal)
- Genera respuesta en otro idioma
- Funciona con micrófono y auriculares Bluetooth

## Estado
MVP funcional – prueba de concepto

UGL no reemplaza idiomas. Conecta significados.
