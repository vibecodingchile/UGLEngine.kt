# UGL Specification – Universal Grounded Language

## 1. Purpose
UGL is a universal intermediate language designed to represent **meaning and intent**
independently of spoken or written languages.

UGL is not a translator.
UGL is a semantic bridge.

---

## 2. Core Principle
Human communication is composed of:
- actors
- intent
- context
- action
- expansion

UGL represents these elements as atomic units.

---

## 3. Atomic Structure

### 3.1 Connection Atoms
Represent who participates in the interaction.

YO
TU
NOSOTROS
VOSOTROS
ELLOS

---

### 3.2 Channeling Atoms
Define the context of interaction.

TIEMPO
LUGAR
SITUACION
EMOCION
URGENCIA
NECESIDAD

---

### 3.3 Action Atoms
Represent intent or action.

SER
ESTAR
TENER
NECESITAR
QUERER
HACER
IR
DECIR
AYUDAR

---

### 3.4 Expansion Atoms
Add depth and precision.

INTENSIDAD
CONDICION
CAUSA
CONSECUENCIA
OBJETIVO

---

## 4. Example

Input (Spanish):
"Necesito ayuda ahora"

UGL Representation:
[YO][NECESITAR][AYUDA][TIEMPO:AHORA][URGENCIA]

Output (English):
"I need help now"

---

## 5. Properties
- Language-independent
- Deterministic core
- Extensible atom sets
- Compatible with AI inference layers
