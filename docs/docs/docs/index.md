# UGL – Universal Grounded Language

## A universal bridge between humans

Speak in your language.
Be understood in another.

---

## How it works

1. You speak
2. UGL detects intent and context
3. Meaning is converted into UGL atoms
4. Output is generated in another language

---

## Example

Input:
"Necesito ayuda"

UGL:
[YO][NECESITAR][AYUDA]

Output:
"I need help"

---

## UGL is not a translator
It is a semantic communication layer.
